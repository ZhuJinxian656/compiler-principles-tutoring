## 如何使用

先阅读第一次讲义梳理编译流程与预测分析，再阅读第三次讲义理解语法分析和属性计算；随后学习第五次的基本块与优化、第七次的运行时环境，最后结合期末讲义做综合复习。建议手工推导自动机、分析表和活动记录，而非仅记忆答案。
